## Cloud Platform Comparison

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 (major GA expansion ~2011–2013) |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| Identity Service | AWS IAM | Microsoft Entra ID | Cloud IAM |
| Primary Strength | Broadest service catalog, market maturity | Enterprise/hybrid integration with Microsoft stack | Data analytics, AI/ML, and Kubernetes |
| Ideal Organizations | Startups to large enterprises needing maximum service breadth | Enterprises already using Windows Server/Microsoft 365 | Data-driven companies and AI/ML-focused teams |

### Discussion Questions

**Which cloud provider offers the broadest range of services?**
AWS generally offers the broadest range of services, with over 200 offerings spanning compute, storage, analytics, IoT, and machine learning. Its head start since 2006 means it has had the most time to build out specialized tools for nearly every use case.

**Which provider best integrates with Microsoft technologies?**
Microsoft Azure is the clear choice for Microsoft integration, since it's built by the same company that makes Windows Server, Microsoft 365, and Active Directory. Organizations already using these tools can extend their existing licenses and identity systems directly into Azure via Microsoft Entra ID.

**Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform tends to lead in this area, largely because Google created Kubernetes and open-sourced it, giving GKE a maturity edge, and because tools like Vertex AI and BigQuery are built on Google's own large-scale data infrastructure.

**Which cloud platform would you personally choose and why?**
Personally, I would lean toward Google Cloud Platform. What stood out to me while researching is how much its tools are built around data and AI — BigQuery and Vertex AI make large-scale analysis and machine learning feel a lot more approachable than I expected, and its per-second billing keeps costs predictable. If I were working on a data-heavy or AI-related project, GCP feels like the most natural fit.
