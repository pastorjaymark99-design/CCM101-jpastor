## Brief Overview

Microsoft Azure is Microsoft's public cloud platform, launched in 2010. It's built to integrate tightly with Microsoft's existing enterprise software ecosystem (Windows Server, Active Directory, Microsoft 365), making it a natural fit for organizations already invested in Microsoft technologies.

## Global Infrastructure

Azure infrastructure is organized into Regions grouped into Region Pairs (for disaster recovery) and further divided into Availability Zones. Azure also has a large number of edge locations through Azure Front Door and the Microsoft global network, plus specialized Government and China regions.

## Cloud Management Console

The Azure Portal is the primary web interface, alongside Azure Cloud Shell (browser-based CLI/PowerShell), the Azure CLI, and Azure Resource Manager (ARM) templates or Bicep for infrastructure-as-code.

## Four (4) Core Services

1. Azure Virtual Machines – On-demand, scalable virtual machines running Windows or Linux.
2. Azure Blob Storage – Object storage for unstructured data, similar in purpose to AWS S3.
3. Microsoft Entra ID (formerly Azure Active Directory) – Identity and access management, deeply integrated with Microsoft 365 and on-prem Active Directory.
4. Azure SQL Database – Fully managed relational database service built on Microsoft SQL Server.

## Three (3) Advantages

1. Microsoft ecosystem integration – Seamless integration with Windows Server, Microsoft 365, and Microsoft Entra ID, making hybrid cloud adoption easier for existing Microsoft shops.
2. Hybrid cloud strength – Azure Arc and Azure Stack let organizations manage on-premises and cloud resources from a single control plane.
3. Enterprise agreements – Licensing benefits (e.g., Azure Hybrid Benefit) for organizations that already hold Microsoft enterprise licenses.

## Typical Enterprise Use Cases

- Enterprises and universities already running Windows Server, Active Directory, or Microsoft 365
- Hybrid cloud deployments that mix on-premises and cloud infrastructure
- .NET application development and modernization
- Enterprise-grade compliance-sensitive workloads (finance, government, healthcare)
