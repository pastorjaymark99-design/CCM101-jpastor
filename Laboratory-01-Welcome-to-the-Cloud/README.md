# Laboratory 01 - Welcome to the Cloud

## Mission Overview
As part of my onboarding as a Junior Cloud Infrastructure Engineer Trainee,
this mission required me to work inside a Linux environment using the
KillerCoda Playground, gather system information, organize files and
directories, and build a professional Cloud Computing Portfolio on GitHub.
This laboratory serves as the foundation for all future activities in
CCM101 - Cloud Computing.

## Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux operating system
- Gather basic system information
- Organize files and directories using Linux commands
- Create and maintain a professional GitHub repository
- Document technical work using Markdown

## Activities Performed
- Launched an Ubuntu 24.04 environment on KillerCoda
- Created a new user (jpastor) with sudo privileges and logged into the account
- Retrieved and recorded system details: Linux distribution, kernel version,
  CPU information, total memory, and available disk space
- Documented findings in system-information.md
- Created a home directory folder structure: Notes, Reports, and Screenshots
- Wrote a personal introduction in about-me.md inside the Notes folder
- Created a public GitHub repository (CCM101-jpastor) to serve as my Cloud
  Computing Portfolio
- Organized the repository with a main README.md and a dedicated
  Laboratory-01-Welcome-to-the-Cloud folder
- Captured and saved screenshots as evidence of each checkpoint
- Committed and pushed all completed work to GitHub

## Linux Commands Used
`sudo adduser`, `usermod`, `su`, `whoami`, `pwd`, `hostname`, `lsb_release -a`,
`uname -r`, `lscpu`, `free -h`, `df -h`, `mkdir`, `cd`, `nano`, `cat`, `ls`

## Skills Learned
Through this laboratory, I learned how to navigate and manage a Linux
system, create and manage user accounts, and retrieve system information
using standard Linux commands. I also practiced organizing files and
directories, writing clear technical documentation in Markdown, and using
Git and GitHub to build and maintain a version-controlled portfolio.
