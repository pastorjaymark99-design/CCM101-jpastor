# Reflection

This was my first laboratory activity in Cloud Computing, and it was also
my first time working inside a KillerCoda Ubuntu environment. Everything
about it felt new at first, from launching a cloud-based Linux playground
to creating a separate user account with sudo privileges instead of just
using the default one provided.

Gathering system information using commands like lsb_release, uname,
lscpu, free, and df gave me a clearer picture of how much detail a cloud
engineer needs to check before working with any environment. I also
realized how useful the terminal is for organizing files and folders
quickly, compared to doing it manually through a graphical interface.

Setting up the GitHub portfolio was the part that challenged me the most.
I had to think carefully about folder structure and naming conventions,
since everything needed to match a specific format for the repository to
look organized and professional. It also reminded me how important it is
to commit and push work regularly, especially since the KillerCoda session
is temporary and any unsaved progress could easily be lost.

Overall, this activity helped me build confidence in using Linux commands,
managing a GitHub repository, and documenting my work properly. It gave me
a solid foundation that I can build on for the rest of the labs this
semester.
