# Laboratory 10 - Enterprise Cloud Architect

## Mission Overview
As the final capstone of CCM101, this project required designing, deploying,
securing, automating, and documenting a complete, production-ready enterprise
infrastructure independently, without step-by-step guidance. The deliverable
is a secure, multi-tier, self-managing private cloud environment.

## Project Summary
- **Application Stack:** WordPress + MySQL
- **Hypervisor:** Oracle VirtualBox
- **Guest OS:** Ubuntu Server 26.04.1 LTS
- **Containerization:** Docker + Docker Compose
- **Security:** UFW (Uncomplicated Firewall)
- **Automation:** Custom Bash backup script + Cron scheduling

## Contents
- `architecture-diagram.png` - Network topology and infrastructure diagram
- `docker-compose.yml` - Multi-tier application definition (WordPress + MySQL)
- `automation-script.sh` - Automated backup script for database and files
- `operational-manual.md` - Full deployment, security, and maintenance guide
- `final-reflection.md` - Reflection synthesizing the journey from Mission 1 to Mission 10
